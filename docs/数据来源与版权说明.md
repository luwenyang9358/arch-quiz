# 数据来源与版权说明

## 一、题库从哪来

本题库**不是官方发布，也没有获得官方授权**。所有题目原文都来自社区志愿整理的公开仓库：

- <https://github.com/wujiaming88/awesome-ruankao>

抓取的具体文件：

| 用途 | 路径模板 |
| --- | --- |
| 真题 · 综合知识 | `真题/系统架构设计师/{年份}/综合知识.md` |
| 真题 · 案例分析（背诵卡） | `真题/系统架构设计师/{年份}/案例分析.md` |
| 真题 · 论文（背诵卡） | `真题/系统架构设计师/{年份}/论文.md` |
| 模拟题 | `模拟题/系统架构设计师/2026年5月/{模拟卷N}/综合知识_{题目,答案}.md` |

`tools/fetch_bank.py` 通过 `raw.githubusercontent.com` 逐文件读取纯文本，不克隆仓库、不下载 PDF。文本里所有题目的著作权归**原命题机构**（工业和信息化部教育与考试中心等）及整理者所有。

本仓库**不包含**题库内容，只包含解析脚本。想做题请自己运行脚本；**请勿二次分发解析出来的题库**。

## 二、解析规则

原始 Markdown 的格式在不同年份并不统一，脚本做了这些兼容：

- 题干按 `## 第N题` / `### 第N题` 切块；
- 答案行兼容 `**答案**：D`、`**参考答案：D**`、`**验证答案：D**` 等多种写法（先剥掉 `**` 再匹配）；
- 选项兼容 `A.` / `A、` / `A．` / `- A.` 四种前缀；
- 选项组分隔兼容 `选项（1）：`、`选项：` 这类多空题写法；
- 解析兼容 `解析：` / `验证依据：` / `答案解析：`；
- 模拟题的考点从答案文件的 `**考点**` 取，取不到的按题目文件的章节标题（`## 一、计算机基础（第1-10题）`）归类，再归一化成 10 个大类。

## 三、已知缺口（重要）

### 1. 各年份题数不齐

| 年份 | 题数 | 说明 |
| --- | --- | --- |
| 2020 下半年 | 75 | |
| 2021 下半年 | 75 | |
| **2022 下半年** | **48** | **原文档缺 27 题的选项，无法还原** |
| 2023 下半年 | 75 | |
| 2024 上半年 | 73 | 缺 2 题 |
| 2024 下半年 | 71 | 缺 4 题 |
| 2025 上半年 | 66 | 缺 9 题 |
| 2025 下半年 | 69 | 缺 6 题 |
| 2026 上半年 | 67 | 缺 8 题 |
| **合计** | **619** | |

缺的部分是原文里就只有题干、没有选项或没有答案的题，脚本选择丢弃而不是猜。

### 2. 多空题 25 道不自动判分

一题干里挖了多个空、共用一组选项的题（如「(1)~(4) 处的空白」），原文的「答案 A」和选项 A–D 不是一一对应的关系。这 25 道题单独标记 `m: 1`，App 里点「查看答案」直接展开，提示「多空题请自行对照答案评分」，不计入正确率。

### 3. 背诵卡 15 张缺答案

案例分析与论文共解析出 85 张卡，其中 15 张原文没有「参考答案 / 答题要点」段落——只有题目。这类卡片留着也是空卡，直接排除，实际可用 **70 张**（案例 38 + 论文 32）。

### 4. 答案可能有错

全部答案与解析均为社区整理，未经官方校对。已知风险点：

- 2020–2021 年的解析较简略，部分只有答案字母没有解释；
- 个别题目的「验证依据」是整理者的推理，不等同于官方评分标准；
- 论文部分的「写作要点」是思路提示，不是范文。

**做题时发现答案可疑，请以教材和官方真题解析为准**，并欢迎提 issue 附上原文截图。

## 四、使用边界

允许：

- 自己 clone 下来跑脚本、改代码、改 UI，用于个人备考；
- 二次开发后开源（保留 MIT 与免责声明）。

不建议：

- 把解析出的 `bank.json` 打包分发、上传网盘、做成付费产品；
- 在任何渠道声称题库「官方」「权威」「押题命中」；
- 去掉本说明后再次分发。

## 五、本地导入的资料

除在线题库外，App 还支持导入你自己手里的讲义：

- 输入是**图片型 PDF**（无文本层也可以），用 `tools/ocr_pdf.swift` 调系统 Vision 框架离线 OCR；
- `tools/import_material.py` 把 OCR 结果整理成三种东西：带答案的选择题（`high.json`）、要点型背诵卡（案例/论文）、论文范文卡；
- 导入时按关键词过滤页眉、页脚、水印、机构名称与联系方式，**成品里不会残留任何第三方机构的标识**；
- 原始 PDF 与解析结果**都不进仓库**，只留在导入者本地。仓库只提供工具，不提供这些内容。

已导入的部分：94 道按章节归类的选择题、110 张案例要点卡、88 张论文要点卡、5 篇论文范文。因为来源是个人购买的讲义，这里不提供原文，也不建议二次分发解析结果。

## 六、视频课

App 的「视频课」页只做两件事：**给出课程清单** + **嵌入官方播放器**（B 站 iframe / 跳转希赛网）。

- 不缓存、不下载、不转码、不二次分发任何视频；
- 视频版权归各平台与讲师所有；
- 第三方 iframe 可能因平台策略变化而失效，失效时用「在浏览器打开」跳转原页面。
